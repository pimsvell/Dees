# Доска

Лёгкая онлайн-доска для рисования и заметок: без зависимостей, без сборки — просто откройте в браузере. Работает офлайн, поддерживает совместную живую работу по ссылке.

## Возможности

- Инструменты: выделение, «рука»/пан, карандаш, маркер, прямые, прямоугольник, эллипс, заметка (sticky), текст, ластик.
- Колесо мыши — прокрутка, `Ctrl` + колесо — масштаб (якорь под курсором), `Shift` + колесо — горизонтально; пробел — временный пан.
- Отмена/повтор (`Ctrl+Z` / `Ctrl+Shift+Z`), дубликаты, копирование/вставка, групповой перенос выделенного.
- Экспорт доски в PNG, PDF и JSON; импорт JSON.
- Хранение досок и папок в браузере (localStorage) либо в выбранной локальной папке (File System Access API, Chromium-based браузеры) — доски лежат в ней как `*.board.json` и обновляются на лету.
- Совместный live по ссылке: автор открывает доску → «Поделиться» → выбирает роль (гость/участник), все видят изменения и курсоры друг друга в реальном времени. Гость видит доску в реальном времени, участник может рисовать. При входе гостя спрашивается имя, отображаемое у его курсора.
- Статичная ссылка-снимок для отправки досок без сервера.

## Локальный запуск

```
start.bat
```

или вручную:

```
python serve.py
```

откроется `http://localhost:8090/`. Для других устройств в сети — `http://<IP-адрес>:8090/` (разрешите доступ в брандмауэре Windows). Требуется только Python 3.7+.

## Публикация на GitHub Pages

Сайт полностью статический, деплоить можно как есть:

1. Создайте репозиторий и залейте содержимое этой папки (вместе с `.nojekyll`).
2. В настройках репозитория: **Settings → Pages → Source: Deploy from branch → main / (root)**.
3. Сайт станет доступен по адресу `https://<user>.github.io/<repo>/`.

На Pages всё работает так же, за одним нюансом: серверные комнаты live-сессий недоступны (нет бэкенда), поэтому приложение автоматически переключается на **P2P-транспорт (PeerJS)** — ваша вкладка становится «сервером», остальные подключаются напрямую по WebRTC через STUN/TURN.

### Ограничения live на Pages

- Вкладка автора live-сессии должна оставаться открытой.
- Всем участникам нужен доступ в интернет для загрузки PeerJS с CDN (`esm.sh`) и подключения к сигнальному серверу PeerJS (`*.peerjs.com`), а в сложном NAT — к TURN-ретранслятору.
- Данные доски и рисунки передаются напрямую между браузерами (P2P); через сигнальный сервер идут только служебные сообщения для установки соединения.

## Совместимость

Chromium-браузеры (Chrome, Edge, Brave, Opera) и Firefox. Синхронизация с локальной папкой — только Chromium (нужен File System Access API). Для мобильных устройств интерфейс пока не адаптирован.

## Тесты

```
run_tests.bat
```

или `python tests\test_app.py` (нужен Selenium: `pip install selenium`). Тесты запускают headless Edge и прогоняют полный набор сценариев интерфейса, шаринга, live и синхронизации.
